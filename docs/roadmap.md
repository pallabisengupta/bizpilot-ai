# Roadmap

## Phase 1: Foundation

- Create Laravel 12 backend API project.
- Create React and Vite frontend project.
- Configure MySQL, Redis, Sanctum, Tailwind CSS, and Docker.
- Establish tenant model and authentication flow.

## Phase 2: Core SaaS

- Business dashboard shell.
- Tenant-scoped user roles.
- CRM lead listing and lead detail views.
- WhatsApp lead intake structure.

## Phase 3: AI and Social Scheduling

- AI social post generation service.
- Facebook scheduling workflow.
- Instagram scheduling workflow.
- Queue jobs for publishing and retries.

## Phase 4: Production Readiness

- Observability and audit logging.
- Billing-ready tenant limits.
- Integration health checks.
- Deployment hardening.
